# Watchlist

Interesting projects that are not ready for the main awesome list yet. We usually move a project into `data/sections.json` once it has a clear license, enough adoption or maintenance signal, and factual metadata that can be verified without guessing.

Last metadata sweep: 2026-10-03, covering 88 entries. Repository availability, canonical URLs, activity, releases, and license metadata were checked; ten candidates received a focused static README/source review. No candidate code, installers, tests, models, or workflows were executed. Coi, AgentAegis, and Transilience Community Tools were subsequently promoted to the main list with scoped descriptions and operational caveats; inclusion is not a security certification.

## Candidates

- [skillxray](https://github.com/munzzyy/skillxray) - GPL-3.0-or-later Python CLI and GitHub Action that statically scans agent skills, Claude Code plugins, and MCP bundles before install for prompt injection, hidden Unicode, dangerous shell commands, credential exfiltration patterns, leaked keys, and auto-running hooks, reporting a letter grade, SARIF, and CI exit codes. Watch because the project is new with little independent adoption; it matches text patterns and never runs the skill, so obfuscated payloads can slip past and a clean grade is not proof that a skill is safe.

- [isMalicious MCP Server](https://github.com/hexablob/ismalicious-mcp-server) — MIT TypeScript stdio client for indicator reputation, CVE context, and prompt-injection/link checks through the commercial isMalicious API. Watch because the September 2026 public mirror has little independent adoption and does not include the hosted detection engine; normal use requires credentials and consumes free or paid quotas, and indicator/text checks send submitted content to the service. Verdict enforcement belongs to the calling application, not the MCP client. This is separate from luantak/is-malicious.
- [plumb-line](https://github.com/slopstopper/plumb-line) — Apache-2.0 coding-agent audit skills, CI checks, and JS/Python provenance primitives that identify unsupported claims and propagate mock or low-confidence labels through derived values. Watch because independent adoption is limited and much of its scope is software reliability rather than adversarial security; skill findings depend on the host model, while deterministic provenance relies on callers supplying honest labels and using the instrumented path. Its threat model addresses mistakes, not a determined attacker or an independently enforced security boundary.
- [JevSec](https://github.com/ccjmcc/jevsec) — MIT research-alpha web-security triage pipeline that aggregates request behavior and combines deterministic rules with local Qwen3-4B decisions through a Jev-compatible runtime, producing findings without blocking traffic. Watch because the October 2026 project has minimal adoption and its small, author-run CSIC replay shows weak risk ranking despite some incremental detection coverage. This is a shadow-mode research aid, not a WAF replacement; local model weights and runtime are separate dependencies, and the demo installer clones an unpinned external runtime.
- [jes](https://github.com/everafterlabs/jes) — Apache-2.0 Python guardrails library for agent prompts, retrieved content, tool calls/results, and responses, combining configurable local transforms with model-based classification and coding-agent hooks. Watch because the September 2026 project has little independent adoption; hosted TypeSafe Jev checks require an API key and transmit evaluated content, while local-model examples are also available. Local secret/PII masking requires the relevant policies and dependencies and is best effort, not automatic protection for every guard. Thresholds need calibration, verdicts can miss attacks or block benign input, and callers must enforce the result.
- [Ziran](https://github.com/taoq-ai/ziran) — Apache-2.0 agent-security testing framework with tool graphs, multi-stage attack campaigns, and adapters for LangChain, CrewAI, MCP, A2A, and remote HTTP agents. Watch because independent adoption is limited; dangerous-chain matching and the side-effect detector use tool-name patterns and reported calls, which do not independently prove successful exploitation or external effects. Adaptive campaigns and model judges need a configured LLM provider, while deterministic analyses do not; active tests can invoke real agent tools and must use isolated, explicitly authorized targets.
- [Small Print](https://github.com/gostanos/smallprint-action) — MIT CLI, GitHub Action, MCP server, and coding-agent plugin that inventory MCP/skill/instruction configuration, compare it with a committed lockfile, and query versioned records of published tool and instruction text. Watch because the September 2026 project has limited independent adoption; `check --locked` is local, while catalog lookups call EmberStack's commercial smallprint.dev API. Live modes can contact remote MCP endpoints or start configured local servers, so they are not passive static checks. Locked metadata or an unchanged published description does not establish runtime safety.
- [20131 Agent Security Runtime](https://github.com/411160007/20131-agentruntime) — Apache-2.0, stdlib-only Go collector that observes agent hooks, relays MCP traffic, evaluates would-block policies, and writes local JSONL audit records. Watch because the September 2026 public project has no independent adoption signal; its Phase 0 runtime is explicitly observe-only, not a blocker or sandbox. Coverage depends on routed hooks/proxy traffic and process discovery, MCP proxy mode starts the configured server, and published detection figures come from a maintainer-run 40-case golden set; current binaries are unsigned or ad-hoc signed.
- [Provenza](https://github.com/kironovlaziz-del/provenza) — Apache-2.0 self-hosted AI-agent governance and audit service with signed delegations, replay nonces, narrowing capabilities and TTLs, and recorded actions bound to prior single-use policy checks. Watch because adoption is limited and enforcement remains cooperative: tools called outside its check/record API are not governed, declared action capabilities remain caller-supplied, and legacy keyless agents have weaker guarantees. Registration supports agent-held public keys as well as server-generated keypairs; `/actions/check` itself is unsigned, and optional governed chat sends masked prompts to configured external model providers.
- [ExecSurface](https://github.com/AETHERXGLOBAL/execsurface) — Apache-2.0 Rust CLI and GitHub Action that observes Linux x86_64 command execution through ptrace, learns a baseline, and reports process, file-access, and network-destination drift. Watch because the September 2026 public alpha has no stars or independent adoption; the inspected command actually runs before the policy verdict, so `BLOCK` can gate subsequent CI steps but cannot prevent effects of that execution. Use disposable isolated environments and review trusted baselines; unchanged behavior is not proof of safety. The Action uploads evidence artifacts to GitHub by default (opt-out available); reports can expose paths and network destinations, and `REVIEW` does not fail CI unless explicitly configured.
- [buried-injections](https://github.com/rudratoshs/buried-injections) — MIT research harness comparing prompt-injection classifiers on AgentDojo-derived text embedded in tool outputs, with benign controls and a separate cross-domain threshold-calibration experiment. Watch because the September 2026 project has limited independent validation: its 629 attack cases reuse 27 goals and one wrapper template, with only 97 benign cases, and it does not run agents or measure attack success. Published rankings depend strongly on thresholds and preprocessing, so neither the default-threshold headline nor calibrated detection rates establish general security performance; model weights are downloaded separately and retain their own licenses.
- [taintgate](https://github.com/rudratoshs/taintgate) — MIT Python in-process policy helper for agent tool calls, with YAML deny/ask/allow rules and normalized string matching between argument values, caller-supplied user messages, and observed tool outputs. Watch because the September 2026 prototype has two stars and limited independent adoption; this is heuristic source matching rather than robust taint tracking or an isolation/authorization boundary. Reformatting, encoding, or laundering values can lose provenance, user-message trust remains the integrator's responsibility, and literal-host checks do not establish DNS-aware SSRF protection.
- [unified-ai-system](https://github.com/happy520ai/unified-ai-system) — Apache-2.0 self-hosted AI/MCP gateway with an opt-in Agent Governance layer for per-call policy checks, approvals, expiry, cascade revocation, and an HMAC-chained audit log. Watch because this is a single-host public preview with seven stars and limited independent adoption; enforcement applies at the configured gateway tool-proxy boundary, not inside arbitrary agent processes, and the local audit chain is not an independently anchored immutable record. The default provider is a local fake for preview use; external providers and optional Langfuse export require deliberate configuration, and Langfuse captures input/output content by default once enabled unless `LANGFUSE_CAPTURE_CONTENT=false` is set.
- [MCP Drift Check](https://github.com/tomelias10/mcp-drift-check) — MIT static Python CLI that flags mutable npm/npx package references in supported MCP configurations and emits text, JSON, Markdown, and SARIF without starting the discovered servers or downloading their packages. Watch because the September 2026 project has no independent adoption signal; an exact version or clean scan does not establish package integrity, safe transitive dependencies, or runtime security. The optional GitHub Action adds an external badge containing the repository identifier and only fails on scanner exit code 1, so other nonzero codes can be ignored; its CI result and network/privacy behavior must not be equated with the local CLI's static analysis.
- [Rouxii](https://anonymous.4open.science/r/rouxii-FBAD/README.md) — MIT research artifact accompanying [Rouxii: Exploiting Honeypots with Deception-Aware AI Pentesters](https://arxiv.org/abs/2609.26555), comparing deception-aware and vanilla AI pentesters against Cowrie, Conpot, GasPot, and real-service controls in an isolated two-host testbed. Watch pending a stable canonical public repository and the promised complete run corpus; the anonymous artifact's MIT file still has a placeholder copyright holder, and the paper's detection rates are author-measured laboratory results, not general operational guarantees. Experiments combine local model inference, containers, SSH, and active reconnaissance/exploitation tooling: use only disposable isolated environments and explicitly authorized targets, not a production honeypot deployment.
- [Supercov](https://github.com/supercorp-ai/supercov) — MIT code-review harness that combines public CWE-mapped model questions, local syntax-based candidate extraction, patch analysis, and optional coverage evidence for coding agents. The public harness and check catalog are available, but findings are review leads, not proof of exploitability or safety.
