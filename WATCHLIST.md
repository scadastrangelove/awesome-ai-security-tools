## Candidates

- [AI Agent Repository Hardening Scanner](https://github.com/OssaBellator/ai-agent-hardening) — MIT zero-dependency Python CLI and GitHub Action for static repository triage of agent instruction files, MCP configuration, selected CI authority patterns, dependency manifests, and common credential-pattern classes; suspected secret values are never printed and target code is not executed. Watch because the October 2026 project is very new with limited independent adoption and a deliberately small rule set; pattern matches are review signals rather than proof of exploitability, and a clean scan is not a security guarantee. The Action requires only `contents: read` and writes the report to the job summary.
- [ToolReplay](https://github.com/brandynfisher/ToolReplay) - MIT dependency-free Python CLI for offline tool-call transcript consistency checks, tool-name allowlist auditing, and SHA-256 log chaining; 182 stars on 2026-10-05. Watch because its narrow post-execution checks do not reproduce whole-agent state or enforce live permissions: replay compares recorded responses for equal tool/argument pairs, and legitimate state changes can explain differences. The unkeyed chain cannot detect a complete rewrite/reseal or tail deletion without an independently trusted anchor. Reconsider with evidence of practical audit use and carefully scoped replay/integrity claims.
- [Stroq](https://github.com/AGGIB/Stroq) - Apache-2.0 local credential-exposure scanner and coding-agent guard using hooks and a stdio MCP proxy; 16 stars on 2026-10-05. Prioritize for follow-up as a substantive but young implementation with limited independent adoption. Default policy allows calls except targeted deny/ask rules; only hooked/proxied paths are covered, and post-tool checks cannot undo effects. Matching depends on indexed secrets, supported encodings, and bounded inputs; optional MCP cloaking stores a reversible plaintext dictionary locally, distinct from the salted-hash index. Recheck host-adapter behavior and operational adoption before promotion.
- [AgentSafe Pipeline](https://github.com/decionis/agent-safe-pipeline) - Apache-2.0 TypeScript execution boundary and HTTP gateway with authorization-grant checks, consumption before dispatch, and outcome journaling; 587 stars on 2026-10-05. Watch because production authority evaluation, grant services, and dossier signing are external or separately licensed; local synthetic authorities are demonstrations, not production substitutes. The remote-authority gateway defaults to SHADOW, configurable FAIL_OPEN exists, and GET requests bypass its mutation-route checks. Protection requires isolating executor credentials and the downstream path from direct agent access. Reconsider when a reproducible authority/deployment configuration and its limits are independently established.
- [OpenBot](https://github.com/CopilotKit/OpenBot) - MIT general-purpose AI coworker platform with per-bot computers, CEL action policy, and audit-before-action; 6,071 stars on 2026-10-05. Watch as a governed platform rather than a dedicated security tool. Application defaults allow all actions, and the example environment enables unauthenticated single-administrator operation; lower-level computer endpoints must not bypass the gateway. Startup also requires CopilotKit Intelligence credentials and separately licensed service/runtime access, even for its local evaluation path. Reconsider with hardened deployment evidence and a clearer independently usable security component.
- [Guardana Control](https://github.com/guardana/control) - Apache-2.0 Go MCP gateway with policy bundles, approvals, and local evidence recording; 22 stars on 2026-10-05. Watch because maintainers explicitly describe it as experimental and not ready to serve as a security boundary. Configured principals are not authenticated caller identity, OBSERVE does not block, and declared SHADOW/WARN modes are not implemented. Fail-closed logic covers routed material actions, with an explicit narrow fail-open-read option; arbitrary agent I/O remains outside the gateway. Recheck production authentication, supported enforcement modes, and independent adoption before promotion.
- [CTRLRun](https://github.com/CTRLRun/ctrlrun) - Apache-2.0 Python action-authorization library and MCP gateway with exact-action approvals, durable effect reservations, and recorded outcomes; 25 stars on 2026-10-05. Prioritize for follow-up because the implementation is substantive but young. Only wrapped/routed calls are checked; in-process policy and storage are not a sandbox against the agent. Duplicate-effect prevention requires stable keys, shared durable storage, and correct outcome reporting, not universal exactly-once delivery. Observe mode forwards otherwise refused calls, and precondition rechecks narrow rather than eliminate TOCTOU. Seek independent integration evidence before main-list promotion.
- [ForgeGuardian](https://github.com/Mah3Sec/ForgeGuardian) - Apache-2.0 Go supply-chain scanner with AI-assisted triage and MCP/model-artifact checks; 106 stars on 2026-10-05. Watch because broad hermetic-build, privacy, and automated-remediation claims exceed the inspected implementation: the process sandbox is not filesystem isolation, and the patch executor's remove branch marks success without removing a dependency. OSV queries disclose package names/versions, registry recipes fetch metadata, and configured hosted models receive analysis input. Reconsider after these claims and execution/remediation paths are reconciled; heuristic MCP findings are not prompt-injection prevention.
- [mcp-audit-tool](https://github.com/graygnatconsole/mcp-audit-tool) - MIT Python CLI for static MCP client-configuration hygiene checks and JSON/SARIF reports; 101 stars on 2026-10-05. Poisoning rules inspect configuration text with regexes, not live tool definitions, and rug-pull findings identify mutable-reference risk rather than observed changes. The inspected audit path does not start configured servers; live probing and definition-hash comparison are roadmap items, not verified current features.
- [OpenTrustBench](https://github.com/eulogik/OpenTrustBench) - Apache-2.0 static agent/MCP source scanner with permission summaries, SARIF, and graded Trust Cards; 13 stars on 2026-10-05.
