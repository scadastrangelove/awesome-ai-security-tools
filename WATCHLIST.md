# Watchlist

Interesting projects that are not ready for the main awesome list yet. We usually move a project into `data/sections.json` once it has a clear license, enough adoption or maintenance signal, and factual metadata that can be verified without guessing.

## Candidates

- [Awesome Agentic Engineering](https://github.com/lindixu6-hash/awesome-agentic-engineering) — MIT self-declared readiness scorecard and CI gate for AI agents, with risk profiles, eight inert prompt-injection fixtures, machine-readable results, and LangGraph.js evaluation adapters that retain node-linked tool and policy traces. Watch because it is broader agent-engineering guidance rather than a security scanner or enforcement control, the project is one day old with minimal adoption, and its CI/evaluation evidence and only listed adopter are author-operated.
- [TRACE](https://github.com/ionsec/trace) — AGPL-3.0 alpha CLI and Go binary for read-only local collection and analysis of AI/LLM forensic artifacts, including model-runner, coding-agent, browser, Docker, network, conversation, credential, timeline, and STIX evidence. Watch because the repository was created on 2026-08-14 with no stars and its large initial implementation arrived in a single commit; the broad capability claims lack independent validation, collected evidence is highly sensitive, and the security-policy version table still lags the current 1.0.1 package.
- [Redcells](https://github.com/awdemos/redcell) — public-beta automated adversarial testing platform for owned or controlled LLMs. Watch because the repository is very new, has no stars yet, and currently has no clear root license file.
- [Signato](https://github.com/Signato-ai/signato-integrations) — commercial-open confidentiality chamber integrations for Claude Code. Watch because the repository is very new, has no stars yet, and the core engine is proprietary while docs and examples are MIT.
- [Agent Trust](https://github.com/Rain-ouroboros/agent-trust) — advisory receipt library for AI-agent prompts, actions, scopes, and tool descriptors. Watch because the repository is very new, has no stars yet, and the current PR wording overstates runtime enforcement and packaging status.
- [Skarn](https://github.com/skarn-security/skarn-action) — GitHub Action wrapper that scans AI coding-assistant session logs for leaked credentials and attack patterns, then emits redacted SARIF and risk output. Watch because the repository is very new and currently has no stars; the public repo is an MIT Action wrapper, while the scanner engine is a proprietary EULA binary that requires a license token.
- [Purser](https://github.com/purser-io/purser) — static security scanner for ML model artifacts across 18+ formats (pickle/PyTorch/Keras/GGUF/ONNX/safetensors) with a data-exfiltration engine, trust_remote_code AST analysis, a country-of-origin/publisher/format policy engine, signed provenance, and CI + Kubernetes admission enforcement. Watch because the repository is very new and currently has low single-digit stars; it ships a clear Apache-2.0 license, is installable (PyPI, signed GHCR images, Helm chart), and is actively maintained.
- [ARIA](https://github.com/sidevworks/aria-sec) — source-available AI security-operations cockpit with governed autonomy, AI-SPM connectors, local-model support, and audit controls. Watch because the repository is one day old with no stars, the author describes it as active solo development with demo-grade parts, and BSL-1.1 requires a commercial production license until its 2030-07-26 GPL conversion.
- [VERITAS Omega Agent Trust Lab](https://github.com/VrtxOmega/veritas-agent-trust-lab) — zero-signup browser challenge for labeling six fixed AI-agent assurance results as clean or tampered before revealing deterministic answers, covering forged verdicts, parameter substitution, nonce replay, correlated evaluators, evidence deletion, and missing telemetry. Watch because the MIT-licensed repository is new and currently has no stars, forks, or eligible external calibration submissions; its release evidence is author-operated and does not establish product efficacy.
- [gate.cat](https://github.com/BGMLAI/gate.cat) — deterministic, fail-closed deny-list that vetoes an AI coding agent's irreversible shell commands (`rm -rf`, disk wipe, prod-DB drop, secret exfiltration) before they run. Watch because the repository is very new and currently has low single-digit stars; it ships a clear Apache-2.0 license, is installable (PyPI, `pip install gate.cat`), publishes its own false-block measurement in the repo, and is actively maintained. Claude Code has a native pre-execution hook; other agents use the provided shell wrapper or integration points.
- [agentsurface](https://github.com/Northbeams-Labs/agentsurface) — local CLI that inventories the AI agent machinery installed on a machine: MCP servers across many clients, desktop extensions, plugins, skills, connectors, scheduled agent tasks, instruction files, and AI browser extensions with their native messaging hosts, reporting what each item declares it can reach. Watch because the repository is very new with minimal adoption; it ships a clear Apache-2.0 license, is installable (Homebrew tap and `go install`), makes no network calls at all (enforced by a CI check that fails the release), and states plainly that it is an inventory: no risk score, no malice judgement, and no prompt-injection detection. Signed archives cover macOS and Linux; Windows is supported through `go install`.
- [Koma](https://github.com/swnotmetal/Project-Koma) — MIT TypeScript monorepo with three npm middleware packages: LLM-based scope filtering, request/audio perimeter checks, and a split-store access pattern. Watch because the project was created in July 2026 and has limited adoption; its Gate layer defaults to fail-open and uses an LLM classifier rather than a demonstrated prompt-injection defence.
- [mcpaudit](https://github.com/AndrewXuTurtle/mcpaudit) — MIT config-side auditor for MCP servers already configured in local AI clients, checking tool poisoning, credential exposure, supply-chain provenance, and advisories without executing the subject server. Watch because the project is newly published with no independent adoption signal; it queries package/advisory registries and, with `--deep`, downloads tarballs for static inspection.
- [Ice Phi Enterprise Shield](https://github.com/Ice-Phi/icephi-python) — MIT Python client for Ice Phi's hosted prompt-security gateway. Watch because the repository is newly published with limited public implementation evidence; its protection runs through a commercial API and therefore needs a `commercial_open` / `requires_api_key` treatment if it later graduates to the main list.
- [Activation-based Model Scanner](https://github.com/GoogleCloudPlatform/activation-model-scanner) — Apache-2.0 PyPI scanner that inspects safety-related activation patterns to flag degraded safety training, abliterated models, and model-identity mismatches. Watch because it is an early, GPU-heavy research implementation with limited adoption despite the strong underlying AASE research.
- [Sandbox Probe](https://github.com/controlplaneio/sandbox-probe) — Apache-2.0 static Go binary that inventories what an agent sandbox can read, write, resolve, reach, and access, then compares baseline and sandbox reports. Watch because it is a very new project with 24 stars, although its evidence-based boundary-measurement approach is compelling.
- [CaMeL](https://github.com/google-research/camel-prompt-injection) — Apache-2.0 research implementation of a prompt-injection defense architecture. Watch because its README explicitly calls it an unsupported research artifact that may contain security bugs, and the repository has not seen a substantive update since 2025-06.
- [Lunar](https://github.com/TheLunarCompany/lunar) — MIT API and MCP governance gateway with open components and commercial production tiers. Watch because the latest tagged release is from 2024-03 despite current commits, so its production packaging and maintenance signal need a closer review before inclusion.
- [bounty-trap-scan](https://github.com/sujeito-operator/bounty-trap-scan) — MIT, stdlib-only Python scanners over GitHub's open `💎 Bounty` issues: one classifies which issues instruct an autonomous contributor to paste its own system prompt into the file it is being paid to change, the other reads the newest 400 pull requests in each of the three largest such repositories and counts what agents actually published back; the raw scan, compliance and attribution JSONs are committed beside the code and each script has a no-network `--selftest`. Watch because the repository was created 2026-08-08, has no stars, and is single-author; today its value is the committed dataset and a reproducible one-line GitHub search rather than adoption or independent verification, and its README carries three dated self-corrections — including one withdrawing a bounty-platform attribution the scanner had never measured.
- [SovereignRoot](https://github.com/BryanFiFife/SovereignRoot) — Apache-2.0 working protocol and local-first browser generator for a cryptographically signed `sovereignty.json`: a human-owned root constraint policy (deny-overrides, attenuation-only) that caps delegated AI-agent authority. Watch because the repository is brand new with no stars yet; it ships a clear Apache-2.0 license, a tagged v0.1.1 release with checksum, a dependency-free static site, and a reference verifier/policy engine, but needs independent adoption and maintenance signal before graduating to the main list.
- [CrewScore](https://github.com/shmindmaster/crewscore) — MIT offline deterministic linter for missing written safeguards in agent system prompts and coding-agent configuration, with 23 public controls, a CLI, GitHub Action, browser checker, and SARIF output. Watch because the repository is only a few weeks old with one star; its corpus study and construct-validity evidence are unusually transparent but author-operated, and written-control coverage is not runtime-security proof.
- [PolicyStrata](https://github.com/raintree-technology/policystrata) — MIT deterministic CI regression tester for policy drift across model-visible tool manifests, semantic validation, SQL compilation, database containment, and result release in data-agent stacks; emits minimized witnesses and SARIF. Watch because the narrowly scoped project is less than two months old with one star; its reproducible fault-model results are useful regression evidence, not independent production-recall or authorization proof.
- [Adrian](https://github.com/secureagentics/Adrian) — Apache-2.0 runtime monitoring and intervention layer that correlates agent actions with available reasoning traces, with managed and GPU-backed self-hosted deployments. Watch because its self-hosted stack requires Docker, an NVIDIA GPU and a local classifier model, while the headline `+35% detection accuracy` and `4x` claims are not Adrian benchmark results: the cited OpenAI paper reports a 60%→95% recall change on two reward-hacking patterns and contains no `4x` metric.
- [Sandlock](https://github.com/multikernel/sandlock) — Apache-2.0 Linux process sandbox using Landlock and seccomp to constrain filesystem, network, and process behavior without a container or VM. Watch because it is young and overlaps existing sandbox entries; its protection depends on Linux kernel capabilities and should be described as process isolation, not prompt-injection defense.
- [LivePI](https://github.com/leizhao7/livepi) — CC BY 4.0 reproducibility artifact for a 2026 benchmark of indirect prompt injection against real service surfaces and current coding-agent harnesses. Watch because the repository has very limited adoption and the benchmark interacts with live accounts and services, requiring particularly careful isolation and authorization.
- [Aegis Memory](https://github.com/quantifylabs/aegis-memory) — Apache-2.0 secure memory/context layer with an offline write gate, unsafe-memory-flow inspection, self-hosted storage, and project-published prompt-injection benchmarks. Watch because adoption is still limited, its benchmark evidence is project-operated, and the main list already includes OWASP Agent Memory Guard in the same emerging niche.
- [OWASP Agent Security Regression Harness](https://github.com/OWASP/Agent-Security-Regression-Harness) — Apache-2.0 regression harness for repeatable agent and MCP abuse cases, policy assertions, and security-control checks. Watch because it is an early OWASP project with limited adoption; it should be evaluated as a regression suite rather than a broad security benchmark.
- [Meta SecAlign](https://github.com/facebookresearch/Meta_SecAlign) — Meta research artifact and model recipe for prompt-injection-resistant foundation models, with evaluations across six security and eight utility benchmarks. Watch because the repository code is CC BY-NC 4.0, model artifacts have separate Llama-family terms, and reproducing the work is GPU-heavy.
- [Agent Security Scanner MCP](https://github.com/sinewaveai/agent-security-scanner-mcp) — MIT MCP server combining project, dependency, package-hallucination, prompt, MCP, and AST/taint scans for coding agents. Watch because the scanner makes unusually broad feature and corpus-size claims for a young project in an already crowded category; the claimed coverage needs focused static and benchmark verification before promotion.
- [agent-approval-gate](https://github.com/Prime-agentai/agent-approval-gate) — MIT `PreToolUse` hook pair for coding agents that blocks spend, account-creation, fund-movement and secret-in-command tool calls before they execute, routes each block to a JSONL approval queue rather than failing the run, exits closed if the guard itself crashes so an internal error cannot be mistaken for an allow, and enforces a per-session token-spend ceiling with a repeat-loop detector; a probe-based verifier fires payloads through the hooks exactly as the harness has them registered, records which caller the harness routed through the hook, and renders the result as a dated evidence report that states in its own body what it does not prove, so a silently misconfigured hook — or one that never fires for subagent tool calls — is detectable rather than indistinguishable from a working one. Watch because the repository was created on 2026-08-10 and has two stars, one of which is the operator's own account and the other arrived inside a ten-repository burst of unrelated stars from a single account, so there is still no external adoption signal; the root license is a clear MIT file, the in-repo suite runs 215/215 across seven files, and the project is written and maintained by an autonomous AI agent under human approval gating, which the README discloses.
